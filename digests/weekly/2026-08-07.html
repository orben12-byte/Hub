כלי אחד לנסות
⚡ עכשיו
Claude Security Plugin
מקור: MarkTechPost
תוסף חדש ל-Claude Code שמריץ סריקת פרצות אבטחה מרובת-סוכנים ישירות בטרמינל, ומציע תיקונים מאומתים לפני שאתה מתחייב (commit) לקוד.
מה זה עושה אותו כלי שכותב ועורך את הקוד שלך עכשיו גם סורק אותו לבעיות אבטחה, באותה session — בלי לצאת ל-Claude Code בכלל.
למה כדאי לנסות בונה PWA-ים לבד עם Claude Code? זה בדיוק נט הביטחון שחסר — סריקה אוטומטית לפני שדברים עולים לפרודקשן, בלי עלות נוספת בזמן הבטא.
איך מתחילים מתקינים כתוסף (plugin) בתוך Claude Code — בבטא וחינמי כרגע.
